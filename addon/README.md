# Dungeon Quests (WoW Forever addon)

The in-game version of the [planner website](https://awsmoli.github.io/dungeon-quests-forever/). It knows your level, class, faction, quest log, the quests you've finished and your party. It plans the quickest pickup route for a dungeon's quests and puts numbered markers on the world map and minimap.

## Install

1. Download **[DungeonQuestsForever.zip](https://github.com/AwsmOli/dungeon-quests-forever/releases/latest/download/DungeonQuestsForever.zip)** (latest release; older ones are on the [releases page](https://github.com/AwsmOli/dungeon-quests-forever/releases)).
2. Unzip it and put the `DungeonQuestsForever` folder in `World of Warcraft\_forever_\Interface\AddOns\`.
3. Restart the game.

Works best with these installed (all optional):

- **QuestieDB / Questie**: quest IDs, so it also knows quests you finished before installing, and exact quest giver positions on Forever's maps
- **Questie or ForeverMaps**: they bring HereBeDragons, which the map markers use
- **TomTom**: used for the waypoint arrow if present; otherwise the game's own map pin is set

## Use

- **Minimap button** (or the addon compartment menu): click to open, right-click to turn map pins on or off. Hover over it to see the next step. Drag it around the minimap.
- **Dungeon list:** every dungeon grouped by level band and sorted by the level you need for all its quests. Gold means you can take them all now, and grey means you're below the dungeon's level. Each row has a bar showing how many of its quests you've done or have in your log.
- **Guide:** click a dungeon to get a step-by-step guide that reads like the quest log:
  - numbered stops, each with checkbox lines ("Pick up …", "Do …", "Turn in …")
  - steps tick off as you accept quests, finish objectives and turn them in, and the last step ("Go in") ticks when you enter the dungeon
  - finished stops fold up
  - the current step is marked, gets a map pin and gets the waypoint
  - click any line to tick it by hand, which helps where the game's state is ambiguous
  - the bottom of the guide lists the quests you pick up inside
- The route starts where you stand and leaves out quests you've finished or can't take yet. **New route** plans it again, for example after leveling or when your party changes.
- **Party:** everyone running the addon shares their quest status for the dungeon you picked. The guide splits pickups between you when that's faster and says who shares what at the meeting point.

Commands: `/dqf` (open), `/dqf <dungeon>` (e.g. `/dqf brd`), `/dqf list`, `/dqf pins`, `/dqf way`, `/dqf optional`, `/dqf minimap`, `/dqf reset`, `/dqf eng gnomish|goblin|none` (your teleport gadget).

## Releasing a new version

1. Raise `## Version` in `DungeonQuestsForever.toc`, for example to `0.4.0`.
2. Commit and push.
3. Tag it with the same version:

```bash
git tag v0.4.0
```

```bash
git push origin v0.4.0
```

The `Release addon` workflow rebuilds the data, runs the tests, checks that the tag matches the TOC, and publishes a GitHub release with `DungeonQuestsForever.zip`. To build the zip locally, run `python tools/package_addon.py`, which writes it to `dist/`.

## How it's built

- `Data.lua` is generated by `python planner/build.py` from the same data as the website. Don't edit it by hand.
- `Engine.lua` is a Lua port of `planner/engine.js`. `addon/tests/parity.lua` and `parity.js` check that both give identical plans for every dungeon.
- `State.lua` reads the quest log and completion, `MapPins.lua` places markers and waypoints, `Comms.lua` syncs the party, `UI.lua` draws the window, and `Core.lua` ties it together.

Tests run under LuaJIT (Lua 5.1, like WoW) with a fake WoW API:

```bash
luajit addon/tests/run.lua
luajit addon/tests/parity.lua > lua.txt && node addon/tests/parity.js > js.txt && diff --strip-trailing-cr lua.txt js.txt
```
